# M10 阶段：6轴姿态传感器驱动 (IMU QMI8658A) 实施计划

本阶段的目标是实现独立的 `qmi8658` 芯片驱动组件（挂载在 I2C1 总线上，设备地址为 `0x6A`）并接入应用层。具体包括传感器复位、寄存器配置宏定义、加速度和角速度的原始与物理数据读取，并在应用层注册控制台指令 `imu_read` 以实时计算并显示开发板当前的 Pitch 和 Roll 倾角。

## 用户审核项

> [!IMPORTANT]
> 1. **关于组件库选择与位置（对比 "waveshare/qmi8658" 与自研）**：
>    * 由于 QMI8658A 协议标准规整，**直接实现轻量级 C 驱动并封装为独立的 `components/qmi8658` 组件是更优的选择**。它能完美沿用我们在 M7（PCA9557）中已经抽象出的 I2C 总线管理模式；
>    * 通过配置 `CTRL1` 中的 `BE = 0` (Little-Endian)，我们可以设置芯片以 Little-Endian 输出，这与 ESP32-S3 原生对齐。从而可以通过**单次 I2C 12字节突发读取**直接映射至 C 语言的 `int16_t` 数组中，执行效率极高。
>    * **总线解耦设计**：驱动组件接口与板级 `bsp_i2c` 解耦，初始化接口接受 `i2c_master_bus_handle_t` 作为参数传入。
> 2. **姿态角（Pitch/Roll）计算逻辑**：
>    * 姿态角（Pitch / Roll）通过板卡上的重力加速度分量计算获得：
>      * $\text{Pitch} = \text{atan2f}(a_x, \sqrt{a_y^2 + a_z^2}) \times 57.29578f$ (度)
>      * $\text{Roll} = \text{atan2f}(a_y, a_z) \times 57.29578f$ (度)
>    * 在控制台中键入 `imu_read` 后，系统将以 100ms 间隔在后台循环读取并更新 Pitch/Roll 以及各轴加速度/角速度数据，当用户按下键盘任意键时退出循环。

### 2. 传感器底层驱动实现

#### [NEW] [qmi8658.h](file:///home/liyun/esp/projects/LCSZP/SZP_BSP/V1/components/qmi8658/include/qmi8658.h)
定义 IMU 的芯片配置宏、API 接口及数据结构：
```c
#pragma once

#include "esp_err.h"
#include "driver/i2c_master.h"
#include <stdint.h>

/* QMI8658A I2C 地址 */
#define QMI8658A_I2C_ADDR       (0x6A)
#define QMI8658A_WHO_AM_I_VAL   (0x05)

/* 寄存器配置宏 */
#define QMI8658A_CTRL1_ADDR_AI  (1 << 6) // 地址自动递增
#define QMI8658A_ACC_FS_8G      (2 << 4) // ±8g量程
#define QMI8658A_ACC_ODR_250HZ  (5 << 0) // 250Hz ODR
#define QMI8658A_GYRO_FS_512DPS  (5 << 4) // ±512dps量程
#define QMI8658A_GYRO_ODR_224HZ  (5 << 0) // 224.2Hz ODR
#define QMI8658A_CTRL5_ACC_LPF_EN  (1 << 0)
#define QMI8658A_CTRL5_GYRO_LPF_EN (1 << 4)
#define QMI8658A_CTRL7_ACC_EN   (1 << 0)
#define QMI8658A_CTRL7_GYRO_EN  (1 << 1)

esp_err_t qmi8658_init(i2c_master_bus_handle_t bus_handle);
esp_err_t qmi8658_read_raw(int16_t acc_raw[3], int16_t gyro_raw[3]);
esp_err_t qmi8658_read_parsed(float acc_g[3], float gyro_dps[3]);
esp_err_t qmi8658_read_temp(float *temp_c);
```

#### [NEW] [qmi8658.c](file:///home/liyun/esp/projects/LCSZP/SZP_BSP/V1/components/qmi8658/qmi8658.c)
实现传感器底层交互与线程安全逻辑：
*   **硬件接口桥接**：接收传入的 I2C 总线句柄，调用 `i2c_master_bus_add_device` 挂载芯片。
*   **软复位**：往 `RESET` (0x60) 寄存器写入 `0xB0`，延时 20ms 等待复位完成。
*   **读取校验**：读取 `WHO_AM_I` (0x00) 并比对是否为 `0x05`。
*   **配置工作参数**：设置 `CTRL1`（启用地址自增）、`CTRL2`/`CTRL3`（设置满量程与 ODR）、`CTRL5`（使能低通滤波器）、`CTRL7`（开启传感器采集）。
*   **突发数据读取**：从 `AX_L` (0x35) 开始突发读取 12 字节，拼接为 Little-Endian 的各轴原始 16 位有符号值。
